# Customer Behavior Analysis

## About the Project
This project explores customer purchasing behavior using Python. I used the Online Retail dataset to understand customer purchases and sales revenue.

## Objectives
- Clean the dataset and handle missing values and duplicates.
- Compare repeat customers with one-time customers.
- Analyze customer revenue and identify high-value customers.
- Study monthly sales trends and popular products.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Main Findings
- Repeat customers accounted for 65.6% of customers.
- Repeat customers contributed 93.1% of the analyzed revenue.
- The top 10% of customers contributed 61.5% of the analyzed revenue.

These findings suggest that repeat and high-value customers are important to the retailer's sales.

## Dataset
**Name:** Online Retail

**Source:** UCI Machine Learning Repository

**Link:** https://archive.ics.uci.edu/dataset/352/online+retail

1. Install the libraries listed in `requirements.txt`.

4. Run the cells in order to perform the analysis.
